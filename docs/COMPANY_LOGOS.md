## 处理与校验

- 下载后检查文件签名；按真实格式保存扩展名，拒绝 HTML 错误页。阿里官网 favicon 实际为 JPEG，vivo 招聘站 favicon 实际为 PNG。
- 栅格图标使用 Pillow 完整解码校验；SVG 使用 XML 解析校验，并检查无脚本、外部引用或事件处理器。
- vivo 标识使用公司官网发布的 SVG 字体中原始 logo-vivo 路径，添加独立 SVG 容器与坐标变换以保持原方向；不重新描绘路径。
- 建信金科来自上海市互联网金融行业协会的企业标识展示，因企业官网当前 DNS 失效。交银金科、联通使用公司官方招聘专题托管资源。
- `dist/company-logos.js` 导出冻结对象 `COMPANY_LOGOS`，值为本地绝对 URL 路径。
