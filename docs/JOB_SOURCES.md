## 剩余限制

- **快手**：公开职位请求仍返回 HTTP 400／校验失败，尚未取得可稳定读取的职位列表；保留官网入口，不用假岗位填充数字。
- **交银金科**：官网连接超时；51job 旧专题的申请链接跳转应届生应用下载页，无法确认当前在招状态。旧招聘资料未冒充当前在招职位。
- **建信金科**：按机构 ID 查询当前开放报名职位，结果为 0。[2027 秋招官方公告](https://job2.ccb.com/cn/job/announcement.html?annoId=20260903100124717047&isImpAnno=1)的报名截止时间为 2026-10-08；该已结束计划未作为在招岗位导入。
- 字节搜索上限 10,000 条，标为部分同步；华为列表有一条缺失标题，跳过并保留历史；蚂蚁、小红书分页可能重叠，去重后标部分同步；飞猪、淘宝闪购按业务名称核验归属，与阿里集团去重。
- 联想、百度、4399 仍为有限列表覆盖；Moka 系目前读取公开职位摘要，完整说明须查看原文。

## 验证与维护

- 76 项自动测试通过；包含分页、重复页、跨公司数据拒绝、失败保留、来源隔离及 39 个本地图标的 HTTP 类型和加载。
- 已通过生产同步入口实测新适配器，将本次验证结果事务写入本机岗位库。
- 浏览器验证：36 家公司图标全部加载、公司筛选与详情、默认折叠、25／50 条滚动加载、空结果状态及桌面／手机布局。
- 入口为 server/official-jobs.mjs；各站点逻辑分在 alibaba-sources、feishu-sources、moka-sources、enterprise-sources、mobile-sources、bank-sources。official-fetch 仅对固定旧 TLS 官网使用 Windows 自带 curl，仍校验证书。
- 同步失败保留原数据；部分读取不下架未读取记录；所有请求限时、分页有上限；不读取用户求职档案到招聘站，也不自动提交申请。
- .runtime/company-research/ 中的实测响应及 SQLite 是本机运行数据，受 Git 忽略，不随源码分发。
